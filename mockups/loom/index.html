how to read the loom

loom — the canvas. Left to right is musical time in bars; down is alternatives. Every pill is a thread: one Stable Audio 3 clip, continued from the tail of its parent. − / = (or ⌘-wheel) zoom the bar scale.

weave — the dashed “what next?” after any leaf (or ✱ on any node) renders what follows. Ask for 1–4 takes of the same prompt: they render as siblings in a bracket, you cue each from the join, then ✓ keep one and the rest are discarded. Pick a LoRA stack and the SA3 knobs (cfg, apg, drift from the parent, negative prompt, seed) in the same popover.

shuttle — a deck's playhead. →A/→B ties a node as that deck's next: through the tree if it's downstream, a jump (or a return) at the seam if not. Ties queue; ⨯ on a tied node or its rail chip unties it. Shift-click, or drop a node on the shuttle, cuts to it on the next bar. Where nothing is tied the shuttle holds the last four bars: the tag counts down to it and turns amber at eight. It never falls silent, and it never picks for you unless auto is on for that deck.

cue — ⌾ auditions a node in the headphones, from the join (four bars before it) so you hear the transition, not just the clip.

rail — each deck's flattened path in the mixer: past · now · next. Also a drop target. explorer — rate, tag, sort and filter the library; “in key” keeps only songs that mix with what a deck is playing.
