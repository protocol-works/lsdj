how to read the loom

  
loom — the canvas. Left to right is musical time in bars; down is alternatives. Every pill is a thread: one Stable Audio 3 clip, continued from the tail of its parent. Zoom with − / + / fit (keys − = Z), ⌘-wheel at the cursor, or drag the ruler up and down like a DAW; sideways scrolls.

  
weave — the dashed “what next?” after any leaf (or ✱ on any node) renders what follows. Ask for 1–4 takes of the same prompt: they render as siblings in a bracket, you cue each from the join, then ✓ keep one and the rest are discarded. Pick a LoRA stack and the SA3 knobs (cfg, apg, drift from the parent, negative prompt, seed) in the same popover.

  
shuttle — a deck's playhead. →A/→B ties a node as that deck's next: through the tree if it's downstream, a jump (or a return) at the seam if not. Ties queue; ⨯ on a tied node unties it. Shift-click, or drop a node on the shuttle, cuts to it on the next bar. Where nothing is tied the shuttle holds the last four bars: the tag counts down to it and turns amber at eight. It never falls silent, and it never picks for you unless auto is on for that deck.

  
cue — ⌾ auditions a node in the headphones, from the join (four bars before it) so you hear the transition, not just the clip. Click inside a waveform to cue from that bar instead; on the node a deck is playing, the click moves that deck's playhead.

  
trim — drag a node's left or right edge to skip an intro or end at the drop (snaps to bars). Like a clip in a DAW the trimmed audio is hidden, not dimmed: the node gets shorter and the tree closes up behind it, because left-to-right is real time.

  
deck panel — what's playing, bars to the seam and what's there, then transport, fader, EQ and FX. Drop a node on it to tie. explorer — rate, tag, sort and filter the library; “in key” keeps only songs that mix with what a deck is playing.

  
render time — ghosts show a live ETA; takes queue one after another; a tied ghost that will miss the seam turns the tag amber with how late it is. With render ahead on (settings) every on-air leaf grows one auto continuation so a hold is a choice, not an accident. A LoRA stack costs ≈2 min per render for the adapter merge, and the popover says so.

  
loop — 4 / 8 / 16 on the deck loops from the current bar (the FLX4's auto-loop); press it again to carry on from wherever the playhead is. A hold at an untied seam is the same thing drawn in amber. A tie back up the tree is a loop at song scale.

  
saving — there is no save button. The loom autosaves under the name in the top bar (click it to rename); the explorer's looms tab lists them. A set is what left the master: ● rec records it, and ⤓ on a deck bounces what that deck played to the songs library.
